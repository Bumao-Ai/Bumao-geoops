# 需要你提供 / 确认的输入清单

按优先级排列。没有这些，代码不会用假数据冒充完成。

## A. 现在就能接：真实模型端点

必须提供：

1. `GEOOPS_MODEL_BASE_URL`：兼容 OpenAI `POST /chat/completions` 的根地址，例如 `http://127.0.0.1:11434/v1`。
2. `GEOOPS_MODEL_NAME`：端点真实存在的模型 id。
3. `GEOOPS_MODEL_API_KEY`：云端服务的密钥；本地 Ollama 可留空或填占位值。
4. 网络可达性：服务进程能访问该地址；若在本机，先启动 Ollama/LM Studio/vLLM。

可选：`GEOOPS_MODEL_TIMEOUT`（秒，默认 60）。

拿到后按 `docs/MODEL_RUNTIME.md` 设置环境变量、重启服务，打开
`/ui/#resources` 点“测试连接”。状态变 `READY` 且返回真实文本，才算接上。

## B. 真实遥感影像与精度样本

当前 `var/demo/*.asc` 只是 3×2 链路样例，不是验收影像。需要你提供：

1. 同一测区、同一 CRS、可对齐的两期或三期真实影像（GeoTIFF 优先；说明是否有云、阴影、分辨率）。
2. 影像使用授权：能否写入本机 `data/`、能否用于演示。
3. 变化检测的地面真值或人工判读样本：至少若干变化图斑与未变化图斑的位置，用于分类精度/漏检率。
4. 若做正射/图件：原始航片、POS/控制点、相机参数、成图比例尺与分幅要求。

没有真值，质检只能做文件/空间层；专业层不能编造 PASS。

## C. 外部 GIS 工具

本机没有 GDAL/QGIS/Rasterio/ENVI。需要你选择一种：

1. 授权安装 GDAL/QGIS（说明安装来源与版本）；或
2. 提供已安装的可执行文件绝对路径与许可；或
3. 明确继续只用标准库实现（则正射、重投影、栅格读写仍受限）。

## D. 审核与权限

1. 审核人姓名/工号与角色（系统管理员、项目负责人、作业人员、审核人员）。
2. 正式环境的令牌发放方式；是否接入统一身份源。
3. 成果归档的目录与保留策略。

## E. Agent 执行策略

当前 Agent 只有目录、依赖和可用性校验，没有执行器。要真跑 Agent，需要你确认：

1. Agent 可调用哪些模型与工具（已有目录 id）。
2. 失败重试、人工接管、最大步数策略。
3. 是否允许模型自动决定下一步；还是只允许按固定顺序执行。

## F. 发布环境

若要脱离本机演示：数据库、对象存储、反向代理、TLS、备份与日志保留要求。

## 当前不需要你提供

- 前端色板、排版、字体：已按 HX 书香 v2.0 落地。
- 项目/任务/成果/质检的数据结构：已实现。
- 本地演示令牌：已在 `var\console-tokens.json`，明文在 `var\console-token.txt`（不提交）。
